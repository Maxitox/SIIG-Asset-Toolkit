# SIIG Asset Toolkit / Space Invaders Infinity Gene Research

Public research repository for the Space Invaders Infinity Gene (SIIG) asset-tooling and reverse-engineering project.

This repository is intended to make the accumulated research, source code, experiments, documentation, and reproducibility material available to future researchers.

## Research principles

The project distinguishes confirmed findings, strongly supported interpretations, hypotheses, and unresolved questions. New contributors should preserve that distinction and provide reproducible evidence for technical claims.

## Project status

The current development line is v2.10.0-dev25. The latest sealed historical release is v2.10.0-dev23 and remains immutable.

## Scope

Research covers the Xbox 360 and PlayStation 3 versions of SIIG and associated formats and systems, including BBX, GMX, TEX, DAT, Visualizer, Stage Explorer, text, audio, and related runtime behavior.
