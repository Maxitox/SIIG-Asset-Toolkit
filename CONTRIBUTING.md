# Contributing

Research contributions are welcome.

## Please include

- Platform and game/build context
- Exact resource or file path
- Reproduction steps
- Relevant hashes where practical
- Evidence supporting the conclusion
- Confidence level: confirmed, strongly supported, hypothesis, or unresolved
- Provenance and licensing information for external material

## Please do not submit

- Commercial game archives or proprietary executable images
- Extracted proprietary game asset dumps
- Credentials or secrets
- Private user paths or personal data
- Third-party material when you do not have permission to redistribute it

When in doubt, submit the finding or metadata rather than the proprietary file itself.
