# SIIG Asset Toolkit 2.10.0-dev22

Dev22 is the Visualizer/desktop-workflow checkpoint built from sealed dev21.

- Rebuilds the Visualizer Simulator around the **June 10 Visualizer Check Mode** footage. The renderer now uses a feedback/trailing-copy surface: magnify/rotate/fade the previous image, then inject the selected SHAPE stamp. Recovered facts remain separate from unresolved visual details: **49 ParameterSet presets, 57 SequenceSet entries, 29 values per parameter row, 10 exact SHAPE resources, and 30/243 retail DAT Visualizer timelines/commands**.
- Completes the Stage Explorer presentation pass: fit-to-panel MAP views, optional composite, native **96×96** tile inspection, and level-4/5 3D route/placement previews. When matching GMXs are present, decoded root AABBs and runtime scale provide model-size proxies; unresolved placement rotation order is not invented.
- Reworks the Simple-mode Boss Assembler into compact **Boss / Variant** selectors with remembered GMX and output folders. All **18** main-game boss families are represented in the project-owner order; 5-6 displays as **NAMELESS** while retaining internal `NO_NAME` compatibility.
- Applies the dev22 boss corrections: outward-facing PROGRESSIVE UFO classic barriers; THE SUN `bos_002b.gmx` as 48 player-protection barriers; MANDALA's 32 center circles as always-present members with unresolved exact transforms; ULTIMATE UFO D9 core authored/visible/hidden inspection control; SQUID body-only redundancy removed; HORNET exposed workflow redirected to the `bos_008b` prism/spread attack; UNKNOWN all-forms export plus optional 30 Hz flicker preview.
- Completes the five-family controller audit without inventing static gameplay assemblies. THE MOON, LADYBUG, OCTOPUS, WATER STRIDER, and NAMELESS/`NO_NAME` now carry explicit controller evidence grades, findings, promotion gates, and supporting function identifiers in `boss-matrix`.
- Adds four GMX glTF visual-pass modes end-to-end: **Separate solid+outline** (default), **Solid only**, **Outline only**, and **Combined**. Native `_F` face/solid and `_E` edge/outline bones are the primary classifier. Combined keeps both passes while merging selected native tracks into one glTF animation clip.
- Game Rip now produces granular live progress in the GUI task log for decompression, extraction, converted outputs, completion counts, and errors. Windows Explorer drag/drop from dev21 remains available.
- Asset Viewer now gives text/code assets thumbnail cards, uses a lightweight SVG DAT timeline preview, opens the correct `SIIG_Asset_Viewer.html`, and can delegate **Open file** to the OS-default application through a localhost-only GUI bridge while preserving direct-offline browser fallback.
- Repairs a dev22 GUI tab-structure regression caught during release gating; the final desktop layout is again `Game Rip`, `Mod Workspace`, `GMX Workbench`, and `Utilities`.

Final supplied-Xbox retail validation completed with **2,593 extracted resources, 1,351 PNGs, 486 glTFs, 86 decoded WAVs + 53 retained WMAs, 92 Stage Explorer entries / 17,335 commands, 30 Visualizer timelines / 243 commands, and 9,384 Asset Viewer entries with 8,669/8,669 previewable thumbnails**. `verify-output` checked **16,544 hashes with zero issues**.

The dependency-free suite passes **106/106**. The source-only audit reports zero proprietary game assets, external executable/container magic, binary members in bundled source archives, private runtime paths, or Python bytecode. Exact Visualizer compositing semantics, Stage Explorer placement rotation order, and unsupported dynamic boss assemblies remain explicitly unresolved.
