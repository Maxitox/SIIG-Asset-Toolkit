# SIIG Asset Toolkit 2.10.0-dev20

Dev20 turns the boss work into one audited console-roster system instead of a sequence of isolated boss releases.

- Adds an 18-family `BOSS_FAMILY_REGISTRY` with exactly one canonical catalog per boss.
- Adds `boss-matrix`, which reports coverage and optionally validates every root GMX from a fresh extraction.
- Keeps **13** families classified as deep runtime reconstructions and explicitly marks **5** as native-inspection-only rather than inventing unproven multipart/gameplay states.
- Adds native-body catalogs for THE MOON, LADYBUG, OCTOPUS, WATER STRIDER, and NO_NAME. Native GMX animation is preserved.
- Fresh Xbox 360 retail validation finds all **18/18** canonical root models and confirms the five new native catalogs export successfully.
- GUI 0.31.0-dev20 exposes Boss matrix diagnostics/action while preserving all prior boss-form controls.
- Cross-boss research/reference/validation artifacts document runtime IDs, root GMXs, catalog coverage, hashes, mesh/bone/animation counts, and evidence boundaries.
- Dependency-free regression suite: **102/102**.

The five native-inspection-only families remain the next deep-runtime research frontier. Identity outer transforms in those catalogs mean native inspection space only; they are not claims about gameplay world position.
