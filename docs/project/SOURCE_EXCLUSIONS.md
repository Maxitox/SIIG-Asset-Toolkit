# Excluded research sources

## The Cutting Room Floor / tcrf.net

TCRF was not used as a source for this project. A retained-artifact audit found no `tcrf.net`, “The Cutting Room Floor,” or standalone `TCRF` reference in the toolkit, provenance records, analysis archives, MAP explorer, or historical releases checked on 2026-08-27.

Project policy is to exclude TCRF from SIIG research: do not browse, scrape, quote, cite, copy, paraphrase, or derive project findings from that site. If independently discovered evidence resembles information published there, preserve the independent game-file, executable, prototype, or primary-document evidence used to reach the conclusion.
