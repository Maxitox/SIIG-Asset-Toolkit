# Project license status

No license has yet been selected for the toolkit's original project code.
Until the project owner chooses and publishes one, the absence of a license
should not be interpreted as permission for unrestricted redistribution.

Third-party notices remain binding independently of the future project license.
In particular, the Xenia-derived texture-addressing adaptation retains the BSD
3-Clause notice in `LICENSES/XENIA-BSD-3-CLAUSE.txt`.

A permissive license such as MIT or BSD-3-Clause would be technically compatible
with the current adapted component, but the final choice belongs to the project
owner and should be made before a public repository release.
